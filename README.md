# Learn FirstMate

FirstMate 的中文入门教程，每章配一个动手练习。

## 这是什么

FirstMate 是一个「agent 发行版」（agent distro）：一个目录，里面装着指令、技能、脚本、规则和状态约定，能把一个通用的编码 agent 变成专门带队干活的 agent。你只跟一个 agent 说话，它就是大副 / firstmate。大副替你派出和监督一队船员 / crewmate，最后交给你可以合并的 PR、你批准过的本地合并，或者一份调研报告。

这个仓库不是 FirstMate 本身，是学它用的。每章讲一项功能：它解决什么问题、有哪些规矩，然后给一个你可以在自己的 FirstMate 上跑一遍的练习。读完做完，你就能在自己的项目上照着用。

教程里关于 FirstMate 的每一条说法，都能在 FirstMate 仓库里找到出处：`AGENTS.md`（大副的工作守则）、`README.md`、`docs/` 下的文档，以及 `bin/` 下脚本开头的注释。每章开头会说明这一章依据的是哪些文件。

## 怎么学

每章两步：

1. **读。** 一章一个主题，一次能读完。哪里拿不准，就去翻这一章列出的原文。
2. **练。** 每章最后有「动手练习」，给出你（船长 / captain）可以直接对大副说的话，以及应该看到什么、怎么检查。练习都是只读或可以撤回的，不会改别人的仓库，也不会做收不回的操作。

最好按顺序读，后面的章节会用到前面讲过的概念。全书的术语译法统一收在 [术语译法表](GLOSSARY.md) 里。

## 章节

第 1 章先讲全貌。第 2 到 5 章跟着一件活往下走，每章讲其中一步。第 6 到 8 章讲活多了以后的事：调研报告、待办队列、监督。第 9 到 11 章讲进阶话题：二副、离席、用什么工具跑船员。第 12 章讲 Relay，它默认关着，不打开就不影响你。
