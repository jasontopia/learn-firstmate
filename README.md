# Learn FirstMate

FirstMate 的中文入门教程与动手练习。

## 这个仓库是什么

FirstMate（大副）是一个「agent distro」- 一个可移植的指令、技能、工具、策略与状态约定的目录，它把一个通用的编码 agent 变成一个专门的 agent。你只跟一个 agent 对话，它替你调度和监督一整支 agent 船员队伍，最后把可以合并的 PR、已批准的本地合并，或者独立的调查报告交到你手上。

这个仓库不是 FirstMate 本身，而是学它的地方。它把 FirstMate 的每一项功能拆成一节，每节先讲清楚这项功能解决什么问题、它的规矩是什么，再给一个你可以真的让 FirstMate 跑一遍的练习。目标很直接：读完并做完之后，你能把这些做法直接用在自己的真实项目上。

教程里所有关于 FirstMate 行为的陈述，都以 FirstMate 仓库里被版本追踪的权威文件为依据 - `AGENTS.md`（大副的职责契约）、`README.md`、`docs/` 下的文档，以及 `bin/` 下脚本的头部注释。每一章都会指出对应的出处，方便你自己回去核对。

## 怎么用它学习

每一节都是同一个节奏，两步：

1. **读一章。** 一章只讲一个主题，篇幅控制在一次能读完。遇到不确定的机制性说法，顺着章节里给出的出处回去读原文 - 这本身也是使用 FirstMate 的基本功。
2. **做一次练习。** 每章末尾有「动手练习」，给出你（船长）可以照着对大副说的中文原话，以及预期会看到什么、怎么判断做成了。练习都是只读或安全可逆的，不会改动别人的仓库，也不会做不可回退的操作。

建议按顺序走。前面几章建立的词汇和心智模型，后面的章节会一直用到。

## 学习路线图

章节顺序是按「先懂全局，再懂每一关，最后懂长期运营」排的：第 1 章先给你整幅地图；第 2 到 5 章沿着一件活的真实旅程往下走，每章钉住旅程中的一关；第 6 到 8 章是从单件活扩展到一支队伍要处理的事 - 知识产出、排队决策、无人值守的监督；第 9 到 11 章是规模、离席、以及「到底是哪个工具在跑你的船员」这类进阶话题；第 12 章单独讲 Relay，它默认关着，不开就完全不影响你。
